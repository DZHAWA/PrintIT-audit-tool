# PrintIT — Hardware Inventory & Audit Solution

Кроссплатформенное решение для автоматизации учета, инвентаризации и аудита парка оргтехники.

## 🛠 Стек технологий
- **Фреймворк:** .NET 10 (.NET MAUI)
- **Архитектура:** MVVM (CommunityToolkit.Mvvm), Dependency Injection
- **Язык:** C#
- **Хранение данных:** JSON, структурированные схемы данных
- **Экспорт отчетности:** Microsoft Word (.docx), Microsoft Excel (.xlsx)

## ✨ Возможности
- Создание сессий инвентаризации с привязкой оборудования к кабинетам.
- Маркировка проблемных принтеров и учет состояния расходных материалов.
- Поиск, сортировка и фильтрация списков оргтехники на базе LINQ.
- Формирование и выгрузка итоговых сводных ведомостей для передачи в работу.
